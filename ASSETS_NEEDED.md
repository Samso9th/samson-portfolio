## 🎨 Design Assets
- Use placeholder colors or solid colors for missing icons
- For folder icons, you can use: https://www.flaticon.com/free-icon/folder_716784
- For app icons, search "macOS app icons" or use solid colored squares as placeholders

## ⚡ Quick Placeholders
If you don't have assets ready:
1. Use colored div elements instead of images temporarily
2. Use emoji as placeholders (📁 📄 🖼️ 🌐)
3. Generate solid color SVGs online
4. Find free icon packs from: Heroicons, Lucide (already installed), or Font Awesome

## 📝 Notes:
- All images should be optimized (compressed)
- Recommended dimensions: Icons 64x64px, Wallpaper 1920x1080px minimum
- Use PNG for icons with transparency, JPG for photos/wallpaper
- Keep total assets folder under 10MB for fast loading
